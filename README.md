# Financial-Eligibility-Risk-Modeling
End-to-end supervised machine learning project using the U.S. Census Income dataset to classify annual income. Implemented preprocessing, feature engineering, oversampling, model selection, hyperparameter tuning, and evaluation while comparing Decision Tree and Neural Network approaches.

## Tech Stack

- Python
- pandas
- NumPy
- scikit-learn
- TensorFlow / Keras
- imbalanced-learn (SMOTE)
- Matplotlib

## Methods

- Data preprocessing and cleaning
- One-hot encoding of categorical features
- Train/test split
- Feature scaling
- SMOTE oversampling for class imbalance
- Hyperparameter tuning with GridSearchCV
- Decision Tree classifier
- Neural Network (TensorFlow/Keras)
- Model evaluation using accuracy and F1 score
